# BookScout
BookScout is a browser-based reading app built with HTML, CSS, and JavaScript.
## Features
- Search real books using the Open Library Search API
- View book covers, titles, authors, publication years, and edition counts
- Save books to a personal reading list
- Mark books as Want to Read, Reading, or Finished
- Add notes to saved books
- Save the reading list in the browser using localStorage
- Export and import the reading list as JSON
- Deploy the app with GitHub Pages
## Files
- `index.html` creates the page structure
- `style.css` controls the design
- `script.js` makes the app interactive
## What I learned
I learned how to use `fetch`, `async/await`, JSON, arrays, localStorage, DOM events, and GitHub Pages
deployment.
